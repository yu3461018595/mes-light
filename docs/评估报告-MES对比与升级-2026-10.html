MES-Light（智工 MES）适用性评估与市面产品对比报告

评估日期：2026-10-06　|　版本：main（含本次升级：批次追溯 / 计件工资 / 车间大屏 / CSV 导出）

一、项目现状功能盘点

系统定位：面向 10–200 人离散制造小厂的轻量云端 MES（零依赖 Node + SQLite + Docker 单容器，可内网部署也可云上部署，PC / 手机 H5 / Android APK 三端共用）。

模块已实现能力
生产执行工单全生命周期（下达→暂停→完工→关闭）、多工序工艺路线、派工到人/班组、工单负责人、工序增删排序、报工（合格/不良/工时、多工序一次申报）、扫码报工二维码
质量闭环IQC/IPQC/FQC 检验点、抽检模式、检查表模板、来料检验闭环（不合格不计库存）、质检员扫码免登录台、异常单全流程（上报→待定级→定级→指派→处理→验证→关闭）、致命级自动暂停工单、超时逐级升级（站内+企微/钉钉 webhook）
物料仓储库存台账（物料×仓×批）、来料/领退料/成品出入库、先进先出跨批扣料、盘点调整、安全库存预警、BOM 单耗与材料损耗分析、产出比（来料→成品）三层分析
统计看板产量/良率/工时趋势、人员排名、FPY 一次合格率、供应商质量、产销对账、异常统计
本次新增计件工资统计、车间大屏看板、批次/工单双向追溯、关键报表 CSV 导出
多端与协同PC 端、手机 H5、Android APK（扫码安装）、消息中心（报工/检验/异常/升级）、公开追溯查询接口
平台特性5 角色 RBAC（管理员/技术员/操作工/质检员）、操作日志、零第三方依赖（无 npm 供应链风险）、Docker 一键部署/更新、SQLite 单文件易备份

二、适用性评估

✅ 适合谁用

  • 10–200 人离散/半离散加工厂：机加、五金、注塑、电子装联、家具、食品分装等；
  • 目前用纸质流转卡 + Excel + 微信群管生产，想要零实施成本、当天上线的场景；
  • 对数据主权/内网部署敏感（客户图纸保密、不接受公有云 SaaS）的工厂——本系统可完全私有化；
  • 已有轻量 ERP（如管家婆、金蝶迷你版），缺车间执行层的补位需求。

⚠️ 不适合谁

  • 需要设备联网采集（PLC/CNC 直采）、OEE 自动计算的重资产工厂（需 IoT 网关，当前未覆盖）；
  • 500 人以上多工厂集团：缺多组织架构、跨厂协同、集团数据标准；
  • 需要与财务/成本核算深度集成的（未对接金蝶/用友等 ERP）；
  • 流程行业（化工/冶金）的连续过程控制场景。

四、本次升级明细（已实现并测试）

  • 批次/工单双向追溯（物料仓储 → 新页签）：输入来料/成品批次号 → 供应商、批次流水、流向工单及其报工与检验；输入工单号 → 用料批次、报工明细、检验记录、成品入库批次、出库客户。数据来自既有流水表，无需新增录入。
  • 计件工资统计（报表 → 新页签）：工资 = 报工合格数 × 工序计件单价（工序档案维护单价），按人汇总工资/合格/不良/工时，支持导出 CSV。
  • 车间生产大屏（/board.html，菜单「车间大屏」）：免登录、深色 TV 版式、30 秒自动刷新——今日产量/良率、在制工单进度条、近 7 日产量柱图、班组产出排行、最新报工、未关闭异常警示。
  • CSV 导出（服务端）：报工记录、收发明细、计件工资支持 ?format=csv（带 BOM，Excel 直开不乱码），便于给 ERP/财务过渡对接。

六、结论

对照市面产品，MES-Light 在单厂小规模场景的功能完整度已达黑湖小工单同档水平，且质量闭环（检验点+抽检+检查表+异常定级升级）明显深于同价位 SaaS；本次补齐追溯、计件工资、车间大屏、报表导出四个 SME 高频刚需后，主要差距收敛到"设备物联 + 排产算法 + ERP 集成"三大项——这些恰是重投入、重实施的模块，对目标客群（10–200 人小厂）并非第一优先级。建议按 P1（设备点检、SOP 附件）→ P2（齐套排产、销售订单）节奏演进，以极低的持有成本形成差异化竞争力。
