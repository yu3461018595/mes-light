# 第一部分：改造方案

## 一、现状盘点（已上线能力）

| 页签 | 能力 | 说明 |
|---|---|---|
| 库存台账 | 按 物料×仓库×批次 实时库存 | 只读，由单据自动重算 |
| 来料入库 | 供应商来料登记 + 检验结论 | 合格才计库存；可关联工单 |
| 成品入库 | 手动入库 + 报工自动入库 + 「同步完工入库」补差 | 与报工联动（report_id 回滚联动） |
| 收发明细 | 全部出入库流水 | 可按物料/类型/工单筛选 |
| 物料档案 | 编码/类别/单位/默认仓库/安全库存上下限 | 支持「从产品导入」 |
| 产销报表 | 报工完工 vs 成品入库 差异对照 + 预警 + CSV | 已有「同步完工入库」 |
| 仓库 | 仓库档案 | — |
| 底层 | inventory_tx 流水表**已预留** `out_pick 领料 / in_return 退料 / out_ship 出库 / adjust 盘点` 四种类型 | 本次直接启用 |
| 手机端 | 库存预警（只读） | 管理层可见 |

## 三、总体设计

### 3.1 新增页签（7 → 9 个）

```
库存台账 | 来料入库 | 领料退料★ | 成品入库 | 成品出库★ | 收发明细 | 产出比★ | 物料档案 | 产销报表 | 仓库
```

- **盘点调整**不单设页签：放在「库存台账」页工具栏（选物料+仓库+批次 → 录实盘数 → 自动生成 adjust 差异流水），符合小系统"轻盘点"习惯。

### 3.2 新增单据与数据流（完全沿用现有模式）

| 单据 | 表 | 流水类型 | 库存影响 | 关键字段 |
|---|---|---|---|---|
| 领料单 | material_issues (type=pick) | `out_pick`（负） | 扣减，**库存不足禁止提交** | 关联工单（必填）、物料、数量、仓库/批次、领料人 |
| 退料单 | material_issues (type=return) | `in_return`（正） | 回增 | 关联工单、退回原因 |
| 成品出库单 | stock_shipments | `out_ship`（负） | 扣减，库存不足禁止 | 客户（选填）、关联工单/销售单号（选填）、物料（成品类）、数量 |
| 盘点调整 | （无独立单据表） | `adjust`（正负皆可） | 按实盘差异一次性调整 | 实盘数、差异说明、盘点人 |

- 单据可改可删（带权限），删除/修改自动**冲销重算**（复用现有 `revertStock`）；全部写入 inventory_tx，操作人、工单关联、单号自动生成（LL/RK/CK+日期+序号）。
- 工单详情新增「领料记录」小区块：显示该工单领料/退料合计，闭环生产视角。

### 3.3 权限

- 新增/修改/删除单据：admin、technician（与现有入库单一致）；查看：全角色。
- 盘点调整：仅 admin、technician；全程留痕（operator + 时间 + 差异说明）。

## 四、投入产出比口径（本次重点）

### 口径 A：来料 → 成品 产出比（P2 主报表）

```
产出比 = 成品入库合格数量 ÷ 来料合格数量 × 100%
```

三层视图（新页签「产出比」）：

1. **总览卡片**：期间内 来料合格总量、成品入库总量、综合产出比、成品入库工单数；支持时间筛选（本月 / 近 3 月 / 近 1 年 / 全部）。
2. **按月趋势**：近 6 个月 来料 vs 成品入库 双柱图 + 产出比折线（复用现有 SVG 图表组件）。
3. **按工单明细表**（精确口径）：
   - 利用现有 `order_id` 关联：每张工单一行 → 关联来料合计 / 关联成品入库合计 / 产出比 / 报工完工数 / 计划数，四列互相印证；
   - 未关联工单的来料单独汇总为「公共来料」行，不混入工单口径；
   - 默认只统计**检验合格**来料（可开关：含待检/全部）；
   - 支持 CSV 导出。

> **诚实标注**：来料与成品的计量单位可能不同（如 来料按 KG、成品按 件），数量比供趋势与管理参考；需要精确考核的工厂建议启用 P3 的「产品单耗」做标准用量对比。

### 口径 B：标准用量对比 / 损耗率（P3 可选）

- 物料档案增加「产品单耗」简易配置（每件成品消耗多少该材料）；
- 报表输出：应耗 = 成品入库 × 单耗 vs 实际领料 → **损耗率**，超阈值标红；
- 领料时可按工单产品自动带出建议用量。

## 五、分期实施建议

| 期 | 内容 | 价值 |
|---|---|---|
| **P1** | 领料退料 + 成品出库 + 盘点调整 + 工单领料记录 | 补齐出入库闭环，库存数字才真实 |
| **P2** | 产出比报表（A 口径三层）+ 收发存汇总 | 用户点名的产出比 + ERP 标配报表 |
| **P3 可选** | 供应商快照下拉、产品单耗/损耗率、手机端领料确认与扫码盘点 | 进阶适用性 |

建议 P1 + P2 一次实施（改动集中在 server.js + warehouse.js + store.js 镜像 + 测试，风格与现有完全一致），P3 待跑一段时间后按需追加。

# 第二部分：使用说明

## 1. 现有功能操作指南（现在就能用）

### 1.1 来料入库
基础数据 → 物料仓储 → 「来料入库」→ 新增：
1. 填来料日期、供应商、选择物料（或直接填名称）、数量；
2. 检验结论选「合格」才会计入库存（待检/不合格只留记录）；
3. 可选关联工单、批次——**关联工单后该笔来料会进入产出比报表的工单口径**；
4. 单号留空自动生成（LM+日期+流水）。

### 1.2 成品入库
- **自动**：检验点工序终检合格放行时自动入库（一期检验模式）；
- **手动**：「成品入库」→ 新增，选工单可自动带出产品与数量；
- **补差**：「产销报表」→「同步完工入库」按工单完工量与已入库量差额补单（幂等可重复执行）。

### 1.3 库存与预警
- 「库存台账」实时可查；低于安全下限标红（缺料预警）、高于上限标黄（积压），并自动推送站内通知（每 10 分钟扫描）。

### 1.4 收发明细
- 所有出入库自动生成流水，可按物料/类型/工单筛选；单据删除或修改会自动冲销并重算，无需手工调账。

### 1.5 产销报表
- 「报工完工 vs 成品入库」差异对照，勾选"仅显示有差异"快速定位漏入库；支持导出 CSV。

## 2. [P1 上线后] 领料 / 退料 / 出库 / 盘点

### 2.1 生产领料（车间向仓库领料）
「领料退料」→ 新增领料单：
1. **必选关联工单**（领料归属到生产任务）；
2. 选物料、数量、仓库（默认带出物料档案仓库）、批次（可选）；
3. 提交即扣库存——**库存不足会被拒绝**，先从来料入库补账；
4. 工单详情页可查看该工单累计领料。

### 2.2 退料（车间退回仓库）
同页签 → 新增退料单：选工单 + 物料 + 数量 + 原因，提交即回增库存。

### 2.3 成品出库（发货/销售）
「成品出库」→ 新增：选成品物料、数量、客户（选填）、关联工单或销售单号（选填）→ 提交扣库存。库存不足禁止出库。

### 2.4 盘点调整
「库存台账」→「盘点调整」按钮：
1. 选物料 + 仓库（+批次），系统显示当前账面数；
2. 录入**实盘数** → 自动算差异 → 填差异说明 → 确认生成调整流水；
3. 盘盈盘亏全程留痕（盘点人/时间/差异），可在收发明细按 `adjust` 类型审计。

### 2.5 对账建议（小厂月度惯例）
月底三步：① 盘点调整把账实对平 → ② 「收发存汇总」核对 期初+收入−发出=期末 → ③ 导出 CSV 存档。

## 3. [P2 上线后] 产出比报表怎么读

- **总览**：先看综合产出比是否稳定；异常波动优先查「按月趋势」定位到月份；
- **按工单表**：产出比明显偏低的工单 → 结合「质量」页异常单与「报工流水」排查（漏检合格判定、来料超标损耗、入库漏记是三大常见原因）；
- **口径提醒**：
  - 来料只统计**检验合格**部分（可开关调整）；
  - 来料与成品单位不同时，数量比仅供参考；
  - 未关联工单的来料计入「公共来料」，不摊入具体工单；
  - 需要精确到材料损耗时，启用 P3「产品单耗」看损耗率。

## 4. 常见问题

| 问题 | 处理 |
|---|---|
| 领料提示库存不足 | 先在「来料入库」补录该批次来料（合格），再领料 |
| 入库单填错 | 单据页直接编辑或删除，库存自动冲销重算，不要手工改台账 |
| 自动入库数量与完工量不一致 | 「产销报表」→「同步完工入库」一键补齐差额 |
| 产出比突然降低 | 先查该期间是否有大批不合格来料被剔除（口径开关验证），再查工单是否漏关联 |
