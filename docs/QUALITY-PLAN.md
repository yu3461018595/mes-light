# 第一部分：改造方案

## 一、现状盘点（已上线能力）

| 能力 | 现状 |
|---|---|
| 检验点 | 工序属性（首检 IQC / 过程检 IPQC / 终检 FQC），工序档案 → 工艺路线 → 工单三级透传 |
| 待检队列 | 报工后自动落「待检」；PC 质量页 + 手机质检台 + 扫码免登录质检台三入口 |
| 检验判定 | 合格放行 / 让步接收（特采）/ 不合格；支持多种不良明细 + 备注；末道放行自动成品入库 |
| 异常单 | 仅重大异常（终检不合格或不良率≥20%）自动开单并暂停工单、推送管理层；一般不合格转返工重检 |
| 闭环流程 | 待认领 → 处理中（原因/措施/处置）→ 待验证 → 验证关闭放行；作废留痕 |
| 超时管理 | 未认领催办（默认 30 分钟）→ 超时升级管理员（默认 240 分钟）→ 企微/钉钉 webhook |
| 统计看板 | 不良帕累托、工序不良率、超期未闭环、平均响应时长；检验记录/异常单 CSV 导出 |
| 字典 | 不良原因库（bad_reasons），「其他」可填具体说明 |

## 三、总体设计

### 3.1 分期概览

```
P1 检验过程增强（质检员日常判定体验，改动集中在质检台 + 检验设置）
P2 来料检验闭环 + 质量分析升级（打通仓储来料单，新增供应商/FPY/趋势分析）
P3 可选增强（打印、AQL，按需再排）
```

### 3.2 P1：检验过程增强

**① 检验方式：全检 / 抽检**

- `inspections` 新增 `inspect_mode`（full 全检 / sample 抽检）与 `sample_qty`（样本数）。
- 待检卡片新增「检验方式」下拉（默认全检，记住上次选择）；选抽检时：
  - 「受检数」变为「样本数」可编辑（默认=报工合格数，可改小）；
  - 不良数按样本登记，判定结论按样本得出；
  - 放行/不合格的业务后果与全检完全一致（放行按报工合格数入库，不受样本影响）。
- 检验记录列表增加「方式」列（全检/抽检 n 件）。

**② 检验项目检查表（Checklist 模板）**

- 新表 `quality_checklists(id, name, process_id, items)`：
  - `items` 为 JSON 数组：`[{name:'外观无划伤', standard:'目视'},{name:'关键尺寸', standard:'φ20±0.05'}]`；
  - 可绑定某道**工序档案**（绑定的工序报工待检时自动带出），也可建通用模板。
- 待检卡片渲染模板项目 → 每项一键 **OK / NG / 不检**；有 NG 项时：
  - 自动把 NG 项追加为不良明细（不良原因=项目名，可再补数量）；
  - 结论默认联动为「不合格」（可手动改回让步）。
- 判定结果 JSON 存入 `inspections.checklist_result`，检验单明细弹窗回显逐项结果。
- 模板维护入口：质量 → 检验设置 新增「检验项目模板」区块（admin/technician）。

**③ 定级阈值可配置**

- `settings` 新增 `critical_ratio`（默认 20）、`minor_ratio`（默认 5）；检验设置页可改（admin）。
- doInspection 定级逻辑读取配置：`fail 且 (终检 || ratio ≥ critical_ratio%)` → critical；`ratio ≤ minor_ratio%` → minor。

**④ 报废与损失登记**

- `quality_issues` 新增 `loss_qty`（报废数量）、`loss_amount`（估计损失金额，元）。
- 异常单「提交处理」时若处置方式=报废，必须填报废数（默认=影响数量）；金额选填。
- 质量看板新增「报废合计 / 损失金额合计」卡片 + 报废 TOP 工序。

### 3.3 P2：来料检验闭环 + 质量分析升级

**① 来料检验（IQC）独立闭环**

- `incoming_materials` 新增 `inspect_status`（waiting 待检 / passed 合格 / failed 不合格）：
  - 新录来料单默认**待检**，暂不计库存；
  - 判定**合格** → 计库存、回写 result=合格（老单已有结论的视为已检，兼容不动）；
  - 判定**不合格** → 不计库存，可一键生成退货记录或质量异常单（source=iqc，按供应商定责提示）。
- 入口两处：质量页新增「来料检验」页签（质检员操作，同待检队列交互）；仓储「来料入库」列表对待检行显示「待检」标记。
- 权限：判定 = admin / technician / inspector，与工序检验一致。

**② 供应商质量统计**（仓储 meta 已有供应商快照，零建档成本）

- 来料合格率 by 供应商（期间筛选）、来料不良帕累托、月度供应商质量表（合格率 + 异常单数）。

**③ 直通率 FPY（一次合格率）**

- 口径：工单末道检验**一次合格放行数** ÷ 首道报工合格数（发生返工重检的工单自动低于 100%）。
- 视图：按产品 / 按班组 / 按月三张表 + 近 6 月趋势折线；放在质量看板新区块。

**④ 质量趋势**

- 按周/月：检验合格率折线、异常开单数柱状、平均闭环时长折线（复用现有 SVG 图表组件）。

### 3.4 P3（可选，按需再排）

- 检验报告 A4 打印（含检验项目结果、不良明细、签字栏）。
- AQL 抽样对照：录批量与检验水平 → 自动建议样本量（GB/T 2828.1 简表）。

### 3.5 权限与兼容

- 所有新接口沿用现有角色模型：admin / technician / inspector 判定，worker 只读与自己相关。
- 老数据零迁移：新列全部 `ALTER TABLE ... ADD COLUMN` 幂等追加，空值走默认逻辑（全检 / 已检 / 阈值 20%/5%）。
- 手机端质检台同步支持：检验方式 + 检查表（简版渲染）。
- 测试：沿用 test_inspection / test_quality_static / test_e2e_quality 体系扩展断言，目标全量 ≥460 断言。

# 第二部分：使用说明

## 一、现有功能（即刻适用）

### 1. 配置检验点（一次性，管理员/技术员）

1. 「基础数据 → 工序档案」编辑工序，检验类型选：**首检 IQC / 过程检 IPQC / 终检 FQC / 不检验**。
   - 约定：QC10=首检、QC20=过程检、QC30=终检（系统已内置标准检验工序）。
2. 配置会随工艺路线自动带到每张新工单；已在生产的老工单可在「工单详情」单独调整（工单管理 → 工序行「检验」按钮）。

### 2. 日常检验流程（质检员）

```
工人报工 → 检验点工序自动落「待检」→ 质检员进入「质量 → 待检队列」（或手机质检台/扫码）
  ├─ 合格放行：填合格数 → 提交 → 工序完工流转（末道放行自动成品入库）
  ├─ 让步接收：特采放行，入库单备注「特采」
  └─ 不合格：填不合格数+不良明细 → 工序挂起待返工
        ├─ 一般异常：返修后重新报工送检（不惊动管理层）
        └─ 重大异常（终检不合格 或 不良率≥20%）：自动开异常单 + 暂停工单 + 推送管理层
```

- 判定不合格后，工序显示「不合格」，工人返修完在报工页重新报工即回到待检。
- 待检卡片可填：不合格数、不良明细（多原因）、备注。

### 3. 质量异常单处理

- 责任人（按工序指派班组的技术员）从「铃铛通知」或「质量 → 质量异常单」进入：
  1. **认领** → 2. 填原因分析 / 处理措施 / 处置方式（返工、返修、让步接收、报废）→ **提交处理**
  3. 技术/管理员**验证关闭** → 工序放行、暂停工单恢复流转。
- 超时链路：30 分钟未认领 → 自动催办；4 小时未处理 → 升级管理员（可在检验设置改时长，支持企微/钉钉群机器人）。
- 误报单由管理员「作废」并填原因。

### 4. 看板与记录

- 「质量看板」：未闭环/致命/超期统计、不良原因帕累托、各工序不良率（≥5% 红色预警）、平均响应时长。
- 「检验记录」「质量异常单」均可导出 CSV（Excel 直接打开）。

## 二、新增功能使用说明[上线后]

### P1 · 检验方式与检查表

- **抽检**：待检卡片「检验方式」选「抽检」，样本数默认=报工数、可改小（如抽 20 检 5）；判定按样本，放行仍按报工合格数。
- **检查表**：管理员在「质量 → 检验设置 → 检验项目模板」新建模板（如「机加终检：外观 OK/NG、尺寸 OK/NG」），绑定到工序；质检时逐项点 OK/NG，有 NG 自动带入不良明细。
- **阈值**：检验设置中可改「严重异常判定占比」（默认 20%）与「轻微异常上限占比」（默认 5%）。
- **报废登记**：异常单处置方式选「报废」时填写报废数与损失金额，质量看板自动汇总。

### P2 · 来料检验与质量分析

- **来料 IQC**：仓库录来料单后单据为「待检」状态、暂不入账 → 质检员在「质量 → 来料检验」判定：合格自动入库；不合格不入库并可转退货/异常单。
- **供应商质量**：质量看板新增来料合格率排名与来料不良帕累托，按供应商考核。
- **直通率 FPY**：看板新区块，按产品/班组/月查看一次合格率，返工越少 FPY 越高。
- **质量趋势**：按周/月合格率、异常数量、闭环时长曲线，月度例会直接截图汇报。
