# 智工 · 轻量生产管理系统（MES Lite）

面向中小制造企业的车间级生产管理系统，对标黑湖小工单的核心场景：**工单下发 → 工序派工 → 现场报工 → 看板/报表**。
零第三方依赖（Node 内置 `http` + `node:sqlite`），开箱即用，无需 npm install。

## 一、快速启动

**方式一：双击 `启动.bat`**（推荐，Windows）

**方式二：命令行**

```bash
cd C:\Users\Admin\WorkBuddy\正常办公\mes
node server.js
```

启动后浏览器访问 <http://localhost:5173>，脚本会自动打开。

> 需要 Node.js 18+（用到 Node 22 内置的 `node:sqlite`）。关闭命令行窗口即停止服务。

## 二、功能说明

### 1. 生产看板
今日产量 / 良率 / 在制工单 / 逾期工单四张指标卡；近 14 天产量与不良趋势；在制工单实时进度；设备状态总览；不良原因 TOP6；人员产出排行。

### 2. 工单管理
- 新建工单时选择产品与工艺路线，**自动生成该路线的全部工序**
- 状态流转：`待下发 → 已下发 → 生产中 ⇄ 已暂停 → 已完成 → 已关闭`
- 派工：为每道工序指定责任人与工作中心/设备
- 详情页展示各工序进度、报工流水，支持撤销误报
- 全部工序报满后工单**自动置为已完成**

### 3. 生产报工（移动端优先）
- 大按钮 + 大字号，适合车间戴手套操作
- 支持**扫码枪**直接扫工单条码（扫码枪等价于键盘输入 + 回车）
- 录入合格数、不良数与不良原因、实动工时
- 报满计划量后工序自动完工，并自动启动下一道工序
- 页面适配手机：底部导航栏，单手可达

### 4. 基础数据
产品、工序、工作中心（含运转/故障/保养状态）、工艺路线（可编辑工序明细：顺序、标准工时、计件单价、绑定设备）、客户、人员、不良原因，全部支持增删改。

### 5. 统计报表
可切换 7/14/30 天区间：产量与不良趋势、每日良率曲线、不良原因分布、人员产出明细（含良率、件均工时）、工单达成率，并支持**一键导出 CSV**。

### 6. 操作日志
记录登录、建单、派工、报工、状态变更、删除等关键动作，便于追溯。

### 7. 关闭工单
工单在 `已下发 / 生产中 / 已暂停 / 已完成` 任一状态下均可关闭。关闭时：
- 自动记录**完工时间**（`finish_time`，若此前未记录）
- 可选填写**关闭原因**（如客户取消、物料不足、转单等），记录在工单详情与日志中
- 关闭后工单不可再报工（与「已完成」同样拦截）

### 8. 微信扫码报工（免登录 H5）
适用于车间「机台码 / 员工码」场景，员工用微信**扫一扫**即可打开报工页，无需登录。

**使用流程**
1. 管理员 / 班组长进入「**扫码报单**」页（或工单详情的「报工二维码」、人员表的「二维码」按钮），生成二维码。
2. 二维码打印张贴到机台，或保存图片发给员工。
3. 员工微信扫一扫 → 打开移动报工页 → 选工序、填合格/不良数 → 提交。

**两种码**
- **工单码**（`/m/report?o=<id>&t=<令牌>`）：谁扫都能报，适合机台公共码。
- **员工码**（`/m/report?w=<id>&t=<令牌>`）：绑定本人，仅该员工可报，适合个人报工；扫码后直接展示其名下在制工单。

**安全说明**：二维码中的令牌由服务端 `HMAC-SHA256(密钥, 类型:ID)` 生成，密钥存于 `mes/.secret`，**不可伪造、可稳定复用**。免登录接口仅校验令牌，不做任何越权读取；工单关闭后不可报工。

## 三、技术说明

```
mes/
├── server.js            # HTTP 服务 + REST API（零依赖）
├── lib/db.js            # SQLite 建表、演示数据、查询封装
├── public/lib/qrcode.js  # vendored 二维码生成库（qrcode-generator，MIT）
├── smoke.js             # 全链路冒烟测试（26 条断言）
├── smoke_qr.js          # 关闭工单 + 扫码报工冒烟测试（18 条断言）
├── data/mes.db          # 数据库文件（删除即恢复演示数据）
├── .secret              # 扫码令牌密钥（随机生成，勿删）
├── public/
│   ├── index.html
│   ├── css/app.css      # 自研样式，移动端优先
│   ├── m/               # 移动端扫码报工 H5（微信内打开，免登录）
│   │   ├── index.html
│   │   └── app.js
│   └── js/
│       ├── api.js       # 接口封装
│       ├── ui.js        # 弹窗、表格、自绘 SVG 图表、二维码弹窗
│       ├── app.js       # 登录、菜单、hash 路由
│       └── views/       # dashboard / orders / report / basic / scan / stats
└── 启动.bat
```

- **后端**：Node 内置 `http` 模块 + 内置 `node:sqlite`，无 Express、无 npm 依赖
- **前端**：原生 JS + hash 路由，图表为手写 SVG，**完全离线可用**
- **认证**：登录返回 token 存 localStorage，服务端按 `admin / leader / worker` 三级角色鉴权
- **数据**：SQLite 单文件，方便备份；删掉 `data/` 目录重启即重新生成演示数据

### 主要接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/login` / `/api/logout` | 登录 / 登出 |
| GET | `/api/meta` | 全部下拉基础数据 |
| GET/POST/PUT/DELETE | `/api/orders` | 工单列表 / 建单 / 改单 / 删单 |
| GET | `/api/orders/:id` | 工单详情（含工序与报工流水） |
| PATCH | `/api/orders/:id/status` | 状态流转 |
| PATCH | `/api/orders/:id/steps/:sid` | 派工 |
| POST | `/api/reports` | 报工（自动累计并推进工序） |
| DELETE | `/api/reports/:id` | 撤销报工 |
| GET | `/api/stats/overview` `trend` `bad` `ranking` `orders` | 各类统计 |
| GET | `/api/scan/:code` | 扫码定位工单/产品 |
| GET | `/api/qr/order/:id` `/api/qr/worker/:id` | 生成工单/员工报工二维码（SVG+链接） |
| GET | `/api/public/order/:id?t=` | 免登录读取工单与工序 |
| GET | `/api/public/worker/:id?t=` | 免登录读取员工在制工单 |
| POST | `/api/public/reports` | 免登录扫码报工（令牌校验） |
| GET | `/api/logs` | 操作日志 |

## 四、常见问题

**端口被占用**：`set PORT=8080 && node server.js`

**想清空数据重新开始**：停止服务 → 删除 `data` 目录 → 重新启动

**想接入真实数据**：直接修改 `lib/db.js` 中的演示数据，或调用上表接口批量导入

**多终端同时使用**：服务监听所有网卡，车间设备访问 `http://<你的内网IP>:5173` 即可（需放开防火墙 5173 端口）
