智工 MES 使用说明书

版本 v1.2 · 2026-10-10 · 适用于 main 分支（含设备点检 / SOP 附件 / 批次追溯 / 计件工资 / 车间大屏）

1. 系统简介与访问方式

智工 MES 是面向中小制造工厂的轻量化制造执行系统，覆盖「工单 → 报工 → 检验 → 异常 → 仓储 → 统计」全流程，支持 PC、手机、Android APP、车间大屏四种使用方式。

手机 H5http://114.117.233.47:8080/m/app/工人报工、质检判定、领料、盘点

2. 角色与权限

角色典型用户主要权限
管理员 admin厂长 / IT全部功能：基础数据、用户管理、工单、报工、检验、异常定级、仓储、报表、日志；可代报工与代上报（行为同操作工口径）
技术员 technician车间主管 / 工艺员建工单与工艺路线、派工、报工、领料、盘点、查看报表；不能定级异常、不能管理用户
操作工 worker一线员工报工（本班组/未指派工单）、上报异常（留存记录，重大可申报）、查看自己的产出与消息
质检员 inspectorQC检验判定（合格/让步/不合格）、抽检、检查表、异常定级、上报异常（直接定级）、扫码质检台
💡 指派了班组的工单，仅该班组人员与质检员/管理层可见可报；未指派班组的工单全员可报。

3. 登录与账号

  1. 浏览器打开 PC 端或手机端地址，输入用户名（中文姓名）与密码登录；
  2. 首次使用请联系管理员开通账号，初始密码 123456；
  3. 登录后点击右上角头像 →「修改密码」及时更改；

4. 上线准备（基础数据）

首次使用按以下顺序录入基础数据（菜单「基础数据」）：

  1. 用户管理：添加员工，指定角色与班组（班组用于派工可见性与计件统计）；
  2. 工序：录入加工工序，维护标准工时与计件单价（计件工资的依据）、是否检验点；可为每道工序上传 SOP 作业指导书 / 图纸（见第 14 章）；
  3. 工作中心（可选）：设备/工位台账；
  4. 设备（菜单「设备」）：建立设备台账并设置点检周期，生成点检二维码贴到机台（见第 13 章）；
  5. 产品：录入成品编码、名称、规格、单位；
  6. 工艺路线：为产品配置工序顺序（可增删、排序、每行指定检验点与单价）；
  7. 仓库 / 物料：建仓库、录物料（设置安全库存上下限）；成品物料可从产品一键导入；
  8. 不良原因：维护报工与检验用的不良原因库。

5. 工单管理

创建与下达

  1. 「工单 → 新建工单」：选产品（自动带出工艺路线）、填计划数量、优先级、计划起止日期，可指派责任班组与工单负责人；
  2. 新工单为「已下达」状态，车间即可开始生产；也可先保存为待下达。

过程管理

  • 工单详情可查看各工序进度、合格/不良数、领发料记录；
  • 未开工前可增加/删除工序、批量排序（已报工的工序不可删、末道工序不可删）；
  • 工序可临时调整检验点（无报工且未进检验流时）；
  • 异常或待料可「暂停」工单，恢复后继续报工；数量不够可「关闭」。
💡 完工数口径：工单完工量 = 各工序合格数的最小值（瓶颈工序口径），末道工序合格后自动触发成品入库（可在仓库关闭自动入库）。

6. 报工（PC / 扫码 / 手机）

方式一：PC「报工」页

  1. 选工单 → 选工序 → 填合格数、不良数（选不良原因）、工时；
  2. 支持一人一次申报多道工序（身兼多岗场景）。

方式二：工单二维码扫码

  1. 管理员在工单详情生成二维码并张贴到工位；
  2. 工人手机扫码 → 免登录报工页 → 输入工号选择自己 → 报工。

方式三：手机 APP「报工」

打开 APP → 首页「我的工单」→ 选工序报工，界面与 H5 一致。

报工后的流转

  • 普通工序：报工即累计完工数，达到计划数自动完工；
  • 检验点工序：报工后工序转「待检」，由质检员判定合格后才放行流转；
  • 填了不良数时选择不良原因，计入统计分析；
  • 报工出错可由管理员在报工记录中删除重报（自动回滚库存联动）。

7. 质量管理与检验

检验点配置（三处入口）

  • 工序档案：设置默认检验点（IQC 来料 / IPQC 过程 / FQC 终检）；
  • 工艺路线编辑器：每行「检验」下拉单独调整；
  • 工单增加工序弹窗：临时指定。

质检员判定

  1. 「质量 → 待检队列」或扫码质检台查看待检工序；
  2. 支持全检 / 抽检（填受检样本数）；可使用检查表模板逐项打分；
  3. 结论三选一：合格（放行流转）/ 让步接收（放行并打特采标记）/ 不合格（工序转返工，工人重新报工后再次进入待检）；
  4. 不合格需填不良明细（原因+数量）；报废登记可录损失数量与金额；
  5. 终检不合格或不良率超阈值（默认 20%，可在质量设置调整）→ 判定致命级：自动开异常单 + 暂停工单。

来料检验（IQC）

「物料仓储 → 来料入库」录单后默认待检、不计入库存；判定合格（或让步）才入库，不合格自动开异常单并留痕供应商。

8. 质量异常单与通知

谁上报、怎么流转

场景等级通知行为
操作工报工时填写异常 / PC 代报「待定级」（可申报严重程度）仅留存记录与统计；申报了严重/致命时通知全体质检员及时定级；不通知管理层
质检员在异常单中定级轻微 / 严重通知责任处理人（工单负责人→班组技术员→创建人）
质检员定级为致命致命通知责任人 + 厂部管理层（站内 + 企微/钉钉群 webhook）
质检员上报异常（上报时直接定级）轻微/严重 → 责任人；致命 → 责任人+管理层同上
检验判定不合格自动开单按定级规则同上；致命级同时暂停工单

异常单生命周期

待处理 → 认领/指派 → 处理中 → 填写原因/措施/处置 → 提交验证 → 验证中 → 验证关闭 已关闭（误报可作废）。

  • 定级：详情页「定级」按钮（仅质检员/管理员）；
  • 超时提醒：长时间未认领提醒班组技术员；只有质检员创建的单超时才升级管理层；
  • 消息在 PC 铃铛、手机 APP「消息」中查看，点击可直达异常单。

9. 物料仓储

常用页签

  • 库存台账：按物料×仓库×批次的实时库存；低于安全下限在首页与预警页提醒；支持盘点调整（按实盘差异自动生成调整流水）；
  • 来料入库：录单（供应商、批次）→ IQC 判定 → 合格入库；
  • 领料退料：领料必选工单；选工单后按 BOM 单耗自动带出建议用量（计划×单耗×(1+损耗%)）一键填入；出库无批次时自动先进先出跨批扣料；
  • 成品入库 / 出库：出库可填客户；删除/修改单据自动红字冲销并重算库存；
  • 收发明细：全部库存变动流水（不可改），支持汇总视图与 CSV 导出；
  • 产出比：成品入库合格 ÷ 来料合格，总览/月度/按工单三层；材料损耗分析：应耗 vs 实领，超 10% 红色预警；
  • 物料档案：维护安全库存、供应商、产品单耗（BOM）；
  • 批次追溯：输入批次号→ 查供应商来源、批次流水、流向工单、出库客户；输入工单号→ 查用料批次、报工、检验、成品批次、出库记录。质量问题时几分钟内完成双向追查。

10. 统计报表与计件工资

  • 产量分析：产量/良率趋势、不良原因分布、人员产出排名、工单达成率；支持导出 CSV；
  • 计件工资：工资 = 报工合格数 × 工序计件单价（在「基础数据 → 工序」维护），按人汇总排名，可按 7/14/30 天切换并导出 CSV 交财务；
  • 质量报表：FPY 一次合格率、供应商合格率、月度质量趋势、报废与损失金额；
  • 产销对账：计划-完工-入库-库存对账表，快速发现漏入库；
  • 服务端导出：报工记录、收发明细、计件工资支持 ?format=csv 直接下载（Excel 打开不乱码）。

13. 设备管理与点检

菜单「设备」（PC 端）维护设备台账，员工通过手机端「设备点检」页或扫描设备二维码执行日常点检。

  1. 建台账（管理员/技术员）：设备编码、名称、型号、安装位置、点检周期（如 1 = 每日一检；0 = 不定期）；
  2. 生成二维码：设备行点「二维码」，打印后贴在机台上，员工扫码直达点检页；
  3. 执行点检：手机端「现场作业 → 设备点检」或扫码，选择 ✅正常 / ⚠️异常，填写说明后提交；可同步把设备状态改为「故障/运转」；
  4. 超期提醒：超过点检周期未点检的设备，列表与手机端会显示红色「已超期 / 未点检」标记；
  5. 异常联动：异常点检可勾选「同时生成质量异常单」，按统一异常口径流转——非检验员生成的为「待定级」（申报严重/致命会通知质检员及时定级），质检员点检可直接定级，致命级上报厂部管理层。
💡 点检记录在设备行点「记录」查看，关联的异常单编号可点击追溯。

14. 工序 SOP / 图纸附件

在「基础数据 → 工序」中可为每道工序上传 SOP 作业指导书或工程图纸，供车间随时查阅。

  1. 工序列表点「传SOP」选择文件（支持 PDF / 图片 / Word / Excel / PPT / TXT / CSV，≤12MB）；已上传显示「换SOP / 删SOP」；
  2. 列表「SOP/图纸」列点击文件名即可在新窗口预览或下载；
  3. 文件存储在服务器 data/uploads/，随数据库一起备份；更换时旧文件自动清理。

15. 常见问题 FAQ

Q：报工时看不到某张工单？
该工单指派了其他班组。找技术员调整指派，或由其班组同事报工。

Q：报工后工序一直是「待检」？
该工序是检验点，等质检员在「质量 → 待检队列」判定合格后自动流转。

Q：工序报错了数量怎么办？
联系管理员在报表/工单中删除该条报工（自动回滚），然后重新报工。

Q：领料时提示库存不足？
按合计口径检查各仓各批次；可先做「来料入库」并完成 IQC 判定。

Q：为什么操作工上报的异常管理层没收到？
这是设计口径：操作工异常仅留存+通知质检员定级，致命级或质检员上报才通知管理层。

Q：忘记密码？
联系管理员在用户管理中重置为初始密码。

Q：数据安全吗？
系统私有化部署在自有服务器，所有接口（除登录/大屏等公开页）需登录访问；请定期用服务器 data/ 目录备份 SQLite 数据库。

16. 术语与规则速查

术语含义
IQC / IPQC / FQC来料检验 / 过程检验 / 最终检验
FPY首次合格率：终检一次性判定合格的比率
让步接收不完全合格但经评审放行使用/出货，系统打特采标记
致命级异常终检不合格或不良率≥阈值（默认 20%），自动暂停工单并上报管理层
待定级操作工上报的异常初始状态，由质检员判定严重等级
完工数口径工单完工 = 各工序合格数最小值（瓶颈）
计件单价工序档案中的元/件，计件工资 = Σ(合格数 × 单价)
先进先出出库未指定批次时按入库先后自动跨批次扣料
